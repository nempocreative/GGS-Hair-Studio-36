name: Visitor tablet layout
description: Responsive behavior requested for the GGS visitor website on iPad and tablet portrait screens.
---

On iPad and tablet portrait, use the phone-responsive website layout and show the visitor bottom tab bar. Keep the four navigation items in a compact centered group rather than stretching each tab across the tablet width; keep Booking as the pink primary tab.

For the “Temui orang di balik gaya” team carousel, show portrait photos in a centered square frame above the profile on tablet portrait, rather than using the desktop two-column crop.

**Why:** The user requested the same portrait layout as the phone, provided the mobile tab bar as reference, and reported that the team photo looked strange and imprecise on iPad.

**How to apply:** When adjusting responsive behavior for the public GGS site, check the homepage, team section, and interior routes in a portrait tablet viewport, not only the employee workspace.
