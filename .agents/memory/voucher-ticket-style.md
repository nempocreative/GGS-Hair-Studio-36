---
name: Voucher ticket style
description: Visual direction for GGS Hair Studio voucher cards.
---

Use a professional, creative printed-ticket look for GGS vouchers: warm paper, subtle depth, and restrained salon branding. Avoid glossy, synthetic, or AI-looking effects; do not add decorative serial numbers or sample codes. Publish a voucher only when its real code is active and within its validity dates.

**Why:** The user asked for attractive, dimensional vouchers that feel like good physical tickets rather than AI-generated graphics, and chose CMS-managed codes so only usable vouchers can be copied.

**How to apply:** Keep the homepage and voucher page cards visually consistent, using print-like details that do not add unnecessary copy or numbers. Keep incomplete or expired offers off visitor pages.
